# GitHub Handle / LinkedIn URL

You should update your GitHub handle to reflect your real name. This makes it easier for the team to identify you when reviewing tasks in GitHub and helps maintain a professional online presence.

If you do not already have one, consider creating a LinkedIn profile as well. Your LinkedIn URL should be professional and, if possible, match your GitHub handle for consistency across platforms.
